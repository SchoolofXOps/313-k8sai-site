Platform Capability by Version

Across this course you build one platform, the Grid, one module at a time. At the end of some modules the course cuts a reference point: a git tag on the public labs repository, such as grid-v0 or grid-v0.5. Think of each tag as a save point in a long game. You can check it out and see the Grid exactly as it stood when that module finished.

This page tells you what the Grid can do at each reference point, what is still broken there, and which module fixes it. Every capability names the lab check that proves it, so you never have to take a line here on trust.

:::info This page is generated

The course generates this page from its own data rather than writing it by hand, and its build fails if the page and the data disagree, or if a capability names a check that its module's checks file does not contain.

:::

What exists in the Grid lists the files a tag restores into grid-platform/. What it can do is wider: it is what that module's lab proved on a running cluster, so most of it is cluster state that the files rebuild rather than something the files hold. Run any script under grid-platform/clusters/ from inside your clone, with the variables the setup page exports.

What is still broken

Still brokenFixed in
A Pod that requests a device stays Pending, because no node advertises one and there is no way yet to request a device by its attributes.M4
The model server has no readiness gate, so its Service sends it requests while it is still starting and they are refused.M8
The autoscaler watches CPU while the queue grows, so it scales on the wrong signal, and a new replica takes requests before it can serve them.M8
The scheduler binds one Pod at a time, so a job that needs all of its Pods together can start with only some of them, and nothing queues or caps scarce devices per team.M5
Nothing yet shows whether the storage path keeps an accelerator busy or leaves it waiting on data.M6
A distributed training job does not survive losing a worker — nothing restarts its Pods as one group or resumes it from a checkpoint.M7
The Service spreads requests round-robin, blind to each replica's queue and cache.M9
